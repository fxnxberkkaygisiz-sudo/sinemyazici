# Görsel Dosyaları

Bu klasöre aşağıdaki görselleri ekleyin. Tümü `person.json` içindeki yollarla eşleşir.
Görsel eklenmezse arayüz zarif bir monogram/placeholder gösterir (site bozulmaz).

| Dosya | Açıklama | Önerilen boyut |
|-------|----------|----------------|
| `profile.jpg` | Profil / portre fotoğrafı | 800×1000 (4:5) |
| `cover.jpg` | Kapak görseli (opsiyonel) | 1600×900 |
| `og.jpg` | Sosyal medya paylaşım görseli | 1200×630 |
| `posts/*.jpg` | Blog yazısı kapakları | 1600×900 |
| `testimonials/*.jpg` | Referans avatarları | 200×200 |

> Yolları değiştirmek isterseniz `person.json` içindeki `profile.avatar`,
> `seo.ogImage` ve ilgili alanları güncelleyin.
